# Wither's Ward

Live site: [wither4096.xyz](https://wither4096.xyz)

Personal devlog and portfolio website.

Powered by [Hugo](https://gohugo.io/) and [PaperMod](https://github.com/adityatelange/hugo-PaperMod) and the [Catppuccin Colour Palette](https://catppuccin.com/)

## Local Development

Clone the repository and initialize the theme submodule:

```bash
git clone --recurse-submodules https://github.com/wither4096/devlogfolio.git
cd devlogfolio
```

Run the local development server:

```bash
hugo server -D
```

The site will be available at `http://localhost:1313`

## Repository Structure

| Directory    | Purpose                      |
|--------------|------------------------------|
| `archetypes/` | Content templates            |
| `assets/`     | Theme customisations         |
| `content/`    | Blog posts and project pages |
| `static/`     | Static media files           |
| `themes/`     | PaperMod theme               |
